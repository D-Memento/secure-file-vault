# Проверка интерфейса

`UiSmoke.java` — отдельная проверка JavaFX, не часть приложения и не часть обычного `mvn test`. Она создаёт тестовое хранилище в каталоге `user.home`, поэтому запускать её можно **только с новым отдельным временным `-Duser.home`**, никогда с реальным домашним каталогом.

В рабочей среде проверка выполнялась через TestFX Monocle 21.0.2 с параметрами:

```text
-Dglass.platform=Monocle
-Dmonocle.platform=Headless
-Dprism.order=sw
-Duser.home=<отдельный пустой временный каталог>
-Djava.io.tmpdir=<доступный временный каталог>
```

Для самостоятельного повторения сначала выполните `mvn package`, затем добавьте к classpath `target/classes`, зависимости приложения и `org.testfx:openjfx-monocle:21.0.2`, скомпилируйте и запустите `UiSmoke`. Monocle не включён в зависимости приложения: для нормального запуска используется нативная графическая среда.

Проверяется переход между экранами создания, основного окна и разблокировки, неверный пароль, успешная повторная разблокировка и запрос закрытия. Нативные файловые диалоги, отображение на физическом дисплее и пяти-минутный таймер этим сценарием не проверяются. Фиксированная парольная строка относится исключительно к одноразовому тесту, не является паролем приложения.
